# Ocean's Eleven

Two decks, one card at a time, first to six hands. Each player draws from their own full 52-card deck; whoever's behind must draw or concede, ties force both sides to draw, and once your opponent hits match point you can't concede anymore.

Play a friend by generating a link — connections are peer-to-peer via [Trystero](https://trystero.dev/) (WebRTC over public Nostr relays), no backend required. Playing against the house (an AI opponent) is coming soon.

Deployed to [avielresnick.com/oceans-eleven](https://avielresnick.com/oceans-eleven) via GitHub Actions, pushing into [Aviel-Resnick.github.io](https://github.com/Aviel-Resnick/Aviel-Resnick.github.io).
